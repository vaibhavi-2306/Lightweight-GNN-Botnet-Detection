# Lightweight GNN-Based Botnet Detection System

## Project Overview

This project focuses on developing a lightweight Graph Neural Network (GNN)-based system for botnet detection using network communication data.

The project is being developed under the domain of Deep Learning for Community Detection and Social Network Analysis.

## Dataset

CSE-CIC-IDS2018 Network Intrusion Detection Dataset
